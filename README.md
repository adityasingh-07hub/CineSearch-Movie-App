# CineSearch - Movie Search and Watchlist App

A desktop app built with Python and Tkinter for the Advanced Practice Programming course.

## Features
- Search movies by name
- Filter by language and rating
- Sort by rating, year or title
- Add and remove movies from a watchlist
- Responsive card layout that fills the window

## Technologies
- Python 3
- Tkinter and ttk (no extra installation needed)

## How to run
1. Install Python 3
2. Download `movie_app.py`
3. Run: `python movie_app.py`
